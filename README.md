# Boatbnb

Stationary dockside boat accommodation marketplace (development starter).

The Next.js application source must be uploaded to this repository before Vercel can build and deploy it.

Never commit `.env.local` or secret API keys. Use Vercel environment variables for `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` (Supabase publishable key).

Reservation requests are not confirmed bookings. Payments and production approval flows are not implemented.
